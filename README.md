# FreeToolHub SEO Edition

GitHub Pages-ready static website.

## Fixing the 404 issue
Upload the ENTIRE contents of this folder to the root of the GitHub Pages repository. Do not upload only index.html. The `tools/` folder must remain beside `index.html`.

The GST page is: `tools/gst-calculator.html`.

## GitHub Pages
Repository Pages should publish from the branch/folder containing `index.html`. After deployment, open:
`https://sehdevverma.github.io/free-tool-hub/`

- Unique titles and meta descriptions
- Canonical URLs for the GitHub Pages site
- Open Graph and Twitter metadata

- robots.txt and absolute-URL sitemap.xml
